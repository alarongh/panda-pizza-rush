# QA публичного билда

Дата проверки: 4 октября 2026. Окружение: Windows, автоматизированные браузеры Playwright. Физический смартфон и Telegram-клиент не использовались.

## Выполненные проверки

| Область | Проверка |
|---|---|
| Ядро | 10 тестов: все препятствия, правильные/неправильные действия, collision, pizza/score, границы полос, пауза/таймеры, restart, finish, storage и 15/30/60/120 fps |
| Проходимость | Весь авторский маршрут пройден обычными событиями клавиатуры, без удаления препятствий и неуязвимости |
| UI | Старт, игра, пауза, проигрыш, финиш, меню, повторный запуск; результаты, рекорд, прогресс и подсказки |
| Управление | Стрелки, WASD, P/Esc, экранные кнопки, PointerEvent-свайпы во всех четырёх направлениях |
| Native touch | Chromium CDP TouchEvent: swipe left/right/up/down в mobile viewport, через реальный браузерный путь обработки touch |
| Lifecycle | blur и visibilitychange переводят в паузу; focus не возобновляет опасный забег автоматически; продолжение по кнопке |
| Аудио | Разблокировка AudioContext пользовательским touch, suspend на паузе, resume по кнопке |
| Хранение | Результат/рекорд переживают reload; битые/недоступные данные безопасно обрабатываются адаптером |
| Размеры | 390×844, 360×640, 320×568, 844×390, 1440×900; игровой viewport 9:16; стартовая кнопка доступна |
| Ошибки | Сбор runtime/console errors и HTTP 4xx/5xx в каждом браузерном сценарии |

Повторяемые команды: `npm test`, `npm run test:browser`, `node tests/native-touch.js`. Для production задаётся `TEST_URL`.

## Исправлено при QA

- В очень узком портретном кадре внутри landscape окна стартовая кнопка уходила вниз. Добавлены размеры UI по ширине контейнера.
- Анимация панды продолжала движение во время паузы. Теперь визуальная фаза определяется игровым временем.
- Дополнена поддержка клавиатурного вызова экранных кнопок и отменённых pointer-событий.
- Статичное окружение вынесено в кеш: sky/архитектура рисуются один раз, динамические детали отдельно.
- Убраны похожие на глаза пятна на голове панды, чтобы ракурс со спины читался однозначно.

## Производительность и ограничения

В Chromium на этом компьютере при Canvas 900×1600 (DPR 2) медианный интервал кадров около 16.7 мс, p95 около 16.8 мс. После кеширования окружения средняя стоимость вызова отрисовки в контрольном замере около 0.11 мс; это локальная метрика, не обещание производительности всех телефонов. Нет внешних runtime-зависимостей; исходная production сборка JS/CSS/HTML занимает около 36 КБ до gzip.

WebKit на Windows проверяет совместимость движка, но не заменяет реальную проверку Safari/iOS. Native touch здесь эмулируется браузером, не физическим экраном. Safe-area CSS предусмотрен; окончательная проверка Telegram toolbar/viewport/haptics остаётся следующему этапу.

Один авторский маршрут, оригинальные временные векторные рисунки, локальные рекорды на устройстве. Утверждённый исходный concept art и полное руководство из старых чатов недоступны для сверки; использовано актуальное текстовое ТЗ. Полные сведения о происхождении решений — в SPEC.md.

## Результаты движков

- Chromium 153: полный набор сценариев пройден, 900 м, 48 кусков, 1380 очков, 74.0 с.
- Firefox 155: полный набор сценариев пройден, 900 м, 48 кусков, 1380 очков, 74.0 с.
- WebKit 26.6: полный набор сценариев пройден, 900 м, 48 кусков, 1380 очков, 74.0 с.
- WebKit отдельно проверен без виртуальных часов: обычный tap старт/пауза/продолжение работают. В сценарии с виртуальным временем для WebKit отключён только ожидатель стабильности положения кнопок Playwright; взаимодействия без этого обхода проверены дополнительным real-time тестом.
- В установленном Windows-порте WebKit отсутствуют AudioContext и webkitAudioContext. Кнопка звука скрывается, игра остаётся рабочей. Аудио проверено в Chromium; аудио Safari/iOS пока не проверено.
- Critical console/runtime errors и HTTP ошибки в завершённых браузерных сценариях отсутствуют.
