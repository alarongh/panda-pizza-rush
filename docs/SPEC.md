# Panda Pizza Rush — единое ТЗ публичного HTML5-билда

Зафиксировано 4 октября 2026. Текущий запрос пользователя имеет приоритет над ранними предложениями.

## Принятые решения

Яркий friendly cartoon 2.5D runner, вертикальный 9:16, вид сзади. Чёрно-белая округлая панда в красном худи с рюкзаком для пиццы автоматически бежит по университетскому двору к двери студика. Три полосы, плавное перестроение, прыжок, подкат. Свайпы в четырёх направлениях, стрелки/WASD, дополнительные экранные кнопки. Space — прыжок, P/Esc — пауза.

Один конечный маршрут 900 м, приблизительно 74 секунды. Скорость растёт от 9 до 16 м/с. Первая часть постепенно знакомит с механиками; далее плотность выше, но каждый ряд имеет свободную полосу. Финальные метры безопасны, дверь приближается. Преподаватель, студент за столом, кофейная станция обходятся; стопки заданий перепрыгиваются; под низким баннером требуется подкат. Любое препятствие также можно обойти. Столкновение завершает попытку.

Кусок пиццы = 10 очков; счёт = пройденные метры + 10 × собранные куски. UI показывает очки, пиццу, дистанцию/прогресс. Состояния: загрузка, меню, игра, пауза, проигрыш, финиш. Рестарт без перезагрузки страницы; результат, лучший счёт и настройка звука сохраняются локально. Возврат в свернутую игру требует осознанного продолжения, чтобы избежать неожиданного столкновения.

## Техника и границы

Canvas 2D + модульный JavaScript + Vite. Для небольшого псевдо-3D раннера отдельный движок не нужен: проекция, фиксированные шаги симуляции, рисование и input имеют самостоятельные модули. Нет внешних CDN, шрифтов или медиа-зависимостей во время игры. Аудио синтезируется локально и разблокируется действием пользователя.

PlatformAdapter/WebPlatformAdapter обрабатывает lifecycle и необязательный tactile feedback. Интерфейс описывает будущий TelegramPlatformAdapter; SDK отсутствует. StorageAdapter/LocalStorageAdapter допускает смену хранилища. Игровое ядро не знает о DOM, Telegram или localStorage. Safe-area-inset и вписанный портретный viewport.

Нет Яндекс Игр, endless, backend, авторизации, рекламы, рейтинга, магазина, бонусных щитов/магнитов/ускорений, валюты, Stars, multiplayer. Ранние альтернативные концепты отменены. Публикация — отдельный GitHub repo и GitHub Pages.

## Условия приёмки

Доступна публичная ссылка; ассеты корректно загружаются под путём репозитория. Проверены desktop, мобильные размеры, touch, keyboard, jump/slide/collisions, сбор/счёт, пауза и lifecycle, проигрыш, финиш, повторные попытки, localStorage, console errors и frame timing. Непроведённые проверки указываются явно в QA.md.
