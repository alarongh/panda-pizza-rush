# Panda Pizza Rush 🍕

Панда, горячая пицца и 900 метров университетского двора. Конечный mobile-first раннер с видом сзади, тремя полосами и оригинальной яркой графикой Canvas 2D.

**[Открыть игру](https://alarongh.github.io/panda-pizza-rush/)**

Одна попытка длится около 74 секунд. Собирайте куски пиццы и доберитесь до студенческого отделения. Скорость и плотность препятствий постепенно растут. Столкновение завершает забег; можно сразу попробовать снова.

## Управление

| Действие | Телефон | Компьютер |
|---|---|---|
| Смена полосы | Свайп влево / вправо | ← / → или A / D |
| Прыжок через стопки заданий | Свайп вверх | ↑ / W / Space |
| Подкат под баннером | Свайп вниз | ↓ / S |
| Пауза | Кнопка Ⅱ | Esc / P |

Также доступны экранные кнопки. Преподаватель, стол с компьютером и кофейная станция требуют смены полосы. Любое препятствие можно обойти. Кусок пиццы даёт 10 очков, метр пути — 1 очко. Рекорд, последний результат и звук сохраняются в браузере.

При сворачивании игра и аудио переходят на паузу. После возвращения нажмите «Продолжить». Звук выключен по умолчанию; включается кнопкой ♪ после взаимодействия с экраном. Установка и аккаунт не нужны.

## Локальный запуск

Node.js 22.12+ или 24+:

```sh
npm ci
npm run dev
```

Откройте адрес, показанный Vite. Для проверки на телефоне в своей локальной сети: `npm run dev -- --host 0.0.0.0`.

```sh
npm test
npm run build
npm run preview
```

`dist/` содержит самостоятельный статический билд. `base: './'` позволяет размещать его в подпапке GitHub Pages без исправления URL ресурсов. Открывайте через HTTP(S), а не двойным щелчком по index.html.

## Структура

```text
src/core.js       Чистая симуляция, collision, score, состояния
src/level.js      Авторский конечный маршрут и подсказки
src/renderer.js   Псевдо-3D проекция, оригинальные рисунки и анимации
src/input.js      Свайпы и клавиатура
src/adapters.js   PlatformAdapter и StorageAdapter
src/audio.js      Синтез коротких звуков
src/main.js       UI и соединение систем
docs/SPEC.md      Актуальное единое ТЗ и происхождение решений
docs/QA.md        Фактически выполненные проверки и ограничения
tests/           Проверки ядра и браузерных сценариев
```

## Проверка в браузерах

Запустите локальный сервер на порту 4173: `npm run dev -- --port 4173`. В другом терминале:

```sh
npx playwright install chromium firefox webkit
npm run test:browser
```

Можно задать `TEST_URL` для проверки production URL и `TEST_ENGINES=chromium` для одного движка. Тесты используют `?qa=1`, включающий диагностический интерфейс. Обычная игра не предоставляет отладочные команды. Артефакты проверки находятся в игнорируемой папке `artifacts/`.

## Публикация

GitHub Actions проверяет ядро, собирает билд и публикует `dist/` на GitHub Pages при push в `main`. В настройках репозитория Pages выберите источник **GitHub Actions**. Для локальной проверки сборки используйте `npm run preview`.

## Следующий этап

**Telegram Mini App integration planned later.** Telegram SDK, бот и сервер в эту версию не входят. Gameplay не обращается к Telegram.WebApp. Будущий TelegramPlatformAdapter реализует интерфейс PlatformAdapter; хранилище можно заменить через StorageAdapter. Затем потребуются подключение бота/меню, lifecycle и safe areas внутри Telegram, haptics и проверки на реальных Android/iOS клиентах.

Текущий рекорд хранится только на данном устройстве и в данном браузере. Один маршрут, без endless, магазина, backend, рекламы или мультиплеера. Графика создана непосредственно для проекта: это аккуратные оригинальные временные векторные ресурсы, которые можно позже заменить утверждёнными ART-ассетами. Внешние картинки, музыка и шрифты не используются. Права на недоступные материалы предыдущих чатов не предполагаются; общая лицензия проекта пока не назначена.
